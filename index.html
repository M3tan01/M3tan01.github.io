OpenElia

PythonMIT license209 commitsgithub.com/M3tan01/OpenElia

An open-source platform for AI-assisted purple-team work. Red, blue and reporting agents use the Model Context Protocol to run an attack, detect it, and respond, all inside a scope gate that refuses to act without a rules-of-engagement file.

Red
  • Recon
  • Vulnerability assessment
  • Exploitation
  • Lateral movement
  • Exfiltration
Blue
  • Tier 1 Sigma / regex monitoring
  • Tier 2 LLM triage
  • Threat hunting
  • Tier 4 containment

Reporter agent closes the loop with an executive report, a MITRE ATT&CK heatmap and a chain of custody.

  • Offensive modules run in ephemeral, rootless Docker containers with all Linux capabilities dropped.
  • Audit entries are chained with HMAC-SHA256, so tampering shows up in the log.
  • A scope check validates targets against roe.json and fails closed when the file is missing. Blue-team remediation stays in simulation mode until explicitly enabled.
  • Red team techniques come from the Atomic Red Team library, with human confirmation in the loop. Adversary profiles such as APT29 and FIN7 are supported.

The project describes itself as a research and lab tool. A multi-operator team server is planned and not built yet.
